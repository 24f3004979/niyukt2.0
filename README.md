# Niyukt 2.0

Simple Web application for placement management

Features
1. Login and registration
2. User Admin control flow
3. Protected routes
4. Simple application tracking system

## Way to start the project

1. Initiate virtual environment for backend to work

```
cd server
python3 -m venv .venv
source .venv/bin/activate
python app.py
```

2. Start the frontend server

```
cd interface
npm install
npm run serve

```

Project starts working at localhost:8080

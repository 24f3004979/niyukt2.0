# Placement Portal Backend + Frontend Implementation Context

## 1. Project Goal

We are building a **placement portal system** with:

* Flask backend
* Flask-SQLAlchemy ORM
* Vue 2 frontend
* Bootstrap styling
* JWT authentication
* Role-based access control

Initial roles:

```
Admin
Student
Company
```

Core workflow:

```
Student
   |
   | register
   |
   v
Active account
   |
   |
   v
Apply to drives


Company
   |
   | register
   |
   v
Pending account
   |
   |
   v
Admin approval
   |
   |
   v
Create drives


Admin
   |
   |
   +---- Manage users
   +---- Approve companies
   +---- Manage drives
```

# 11. Backend Error Handling

Problem discovered:

SQLAlchemy crashes on:

```
UNIQUE constraint failed
```

Example:

Duplicate email:

```
IntegrityError
```

Solution:

Central error handler.

Handles:

```
404

500

IntegrityError
```

Returns JSON:

Example:

```json
{
"message":
"Database constraint violation"
}
```

instead of Flask crash.

# 12. API Response Improvement Plan

Current:

```json
{
"message":"created"
}
```

Future standardized response:

Success:

```json
{
"success":true,
"message":"User created",
"data":{}
}
```

Error:

```json
{
"success":false,

"error":{
    "code":"EMAIL_EXISTS",
    "message":
    "Email already registered"
}

}
```

This allows Vue to handle all modules uniformly.
